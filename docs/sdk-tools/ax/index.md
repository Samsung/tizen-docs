# AX: AI Tools for Tizen Development

The AX section collects the resources that let AI coding assistants work with the Tizen platform. Where the VS Code and Visual Studio sections describe the tools you operate yourself, the AX section describes what an AI coding assistant such as Claude Code, Cline, Codex CLI, or Gemini CLI can install and use on your behalf.

These resources do not depend on a particular IDE or application model. The same skills serve .NET, native, and web application development.

## Categories

The section is organized into four categories:

| Category | Contents |
|----------|----------|
| **Skills** | Skills and plugins that an AI coding assistant installs to automate Tizen development tasks. |
| **Tools** | Executables and servers that an AI coding assistant calls, such as command-line tools and MCP servers. |
| **Knowledge** | Tizen documentation and API knowledge prepared for retrieval by AI coding assistants. |
| **Agents** | Ready-to-run agents that carry out larger Tizen development workflows. |

Skills is the first category with published content. The other categories are listed here so that you know where future resources will appear.

## Skills

- [Tizen Agent Skills](skills/tizen-agent-skills/index.md): Samsung's open-source collection of agent skills that install the Tizen SDK, create and build projects, manage emulators and devices, and debug applications from natural-language requests.
