# Tizen Web API References

The Tizen Web API specifications consist of a collection of existing standards, such as W3C and Khronos, and Tizen-specific APIs that provide access to device platform capabilities.

The following API references provide descriptions of all the APIs that can be used for creating Tizen Web applications.

- [Tizen Web Device API Reference for TV](latest/device_api/tv/index.html)

  This reference provides the Tizen Web device API specifications.

- [W3C/HTML5 and Supplementaries API Reference for TV](latest/w3c_api/w3c_api_tv.html)

  This reference provides the Tizen W3C/HTML5 and some supplementary API specifications.
