RPCPort API

The RPC Port API provides functions for inter-process communication (IPC) between Tizen applications.

It allows applications to establish communication channels, serialize and deserialize data, and exchange messages using a protocol-based messaging system.

The RPC Port API is based on the native rpc-port library and provides:

  • Parcel - A serialization container for marshalling data across process boundaries
  • Proxy/Stub - Client-server communication pattern for RPC calls
  • Port - Communication channels (MAIN and CALLBACK)

For more information on the RPC Port features, see RPC Port Guide.

Since: 10.1

1. Type Definitions

1.1. PortType

Enumeration for port types. 
  enum PortType { "MAIN", "CALLBACK" };

Since: 10.1

The following values are supported:

  • MAIN - The main communication channel
  • CALLBACK - The channel for callbacks

2. Interfaces

2.1. RPCPortObject

The RPCPortObject interface defines what is instantiated by the Tizen object from the Tizen platform. 
  [NoInterfaceObject] interface RPCPortObject {
    readonly attribute RPCPortManager rpcport;
  };
  Tizen implements RPCPortObject;

Since: 10.1

There is a tizen.rpcport object that allows access to the RPC Port API.

Attributes

  • readonly RPCPortManager rpcport
    Object representing the RPC Port manager.

    Since: 10.1

2.2. RPCPortEventCallback

The RPCPortEventCallback interface specifies a callback to be invoked when an event is received. 
  [Callback=FunctionOnly, NoInterfaceObject] interface RPCPortEventCallback {
    void onreceived(octet[] data);
  };

Since: 10.1

Methods

onreceived
Called when an event is received. 
void onreceived(octet[] data);

Since: 10.1

Parameters:

  • data: Event data as a byte array.

Code example:

try
{
  var onSuccessCB = function(data)
  {
    console.log("RPCPortEventCallback called successfully with data: " + data);

  var watchId = tizen.rpcport.addEventReceiver("com.example.myevent", onSuccessCB);
}
catch (err)
{
  console.log(err.name + ": " + err.message);
}

Exceptions:

  • WebAPIException

    • with error type AbortError, if any error occurs.

Code example:

/* ... later ... */
tizen.rpcport.removeEventReceiver(watchId);

2.4. Parcel

The Parcel interface provides serialization and deserialization capabilities. 
  interface Parcel {
    octet[] toBytes();
    void send(Port port) raises(WebAPIException);
    void setTagEx(octet major, octet minor, octet patch, octet proto, octet flags) raises(WebAPIException);
    long getSeqNum() raises(WebAPIException);
    void dispose() raises(WebAPIException);
    void writeByte(byte value) raises(WebAPIException);
    void writeInt16(short value) raises(WebAPIException);
    void writeInt32(long value) raises(WebAPIException);
    void writeInt64(long long value) raises(WebAPIException);
    void writeDouble(double value) raises(WebAPIException);
    void writeBool(boolean value) raises(WebAPIException);
    void writeString(DOMString value) raises(WebAPIException);
    void writeArrayCount(unsigned long count) raises(WebAPIException);
    void writeBundle(Bundle bundle) raises(WebAPIException);
    byte readByte() raises(WebAPIException);
    short readInt16() raises(WebAPIException);
    long readInt32() raises(WebAPIException);
    long long readInt64() raises(WebAPIException);
    double readDouble() raises(WebAPIException);
    boolean readBool() raises(WebAPIException);
    DOMString readString() raises(WebAPIException);
    unsigned long readArrayCount() raises(WebAPIException);
    Bundle readBundle() raises(WebAPIException);
  };

Since: 10.1

A Parcel is a container for marshalling data across process boundaries. It supports writing and reading various primitive types, strings, arrays, and bundles. Writing operations append data to the parcel, while reading operations consume data sequentially. It is the application's responsibility to write and read the same types of data in the same order to avoid data corruption.

Code example:

/* Example: Creating a parcel, setting metadata, writing data, and sending */
var parcel = tizen.rpcport.createEmptyParcel();
parcel.setTagEx(1, 0, 0, 1, 0);  /* Set version and protocol info */
parcel.writeInt32(42);           /* Write an integer */
parcel.writeString("Hello");     /* Write a string */
var port = proxy.getPort(tizen.rpcport.PortType.MAIN);
parcel.send(port);  /* Send the parcel */

2.5. Port

The Port interface represents a communication channel. 
  interface Port {
    void disconnect() raises(WebAPIException);
    void shareFile(DOMString path) raises(WebAPIException);
    void shareFiles(DOMString[] paths) raises(WebAPIException);
  };

Since: 10.1

Applications obtain Port objects by calling the getPort() method of ProxyBase or StubBase implementations.

Methods

disconnect
Disconnects the port. 
void disconnect();

Since: 10.1

Exceptions:

  • WebAPIException

    • with error type InvalidValuesError, if the port handle is invalid.

    • with error type AbortError, if any other error occurs.

Code example:

var port = proxy.getPort(tizen.rpcport.PortType.MAIN);
port.disconnect();
shareFile
Shares a private file through the port. 
void shareFile(DOMString path);

Since: 10.1

The file path must be under the caller application's data path. The target application will be granted temporary permission to access the file.

Parameters:

  • path: The path of the file to share.

Exceptions:

  • WebAPIException

    • with error type TypeMismatchError, if path is not a string.

    • with error type InvalidValuesError, if the port handle is invalid or path is invalid.

    • with error type IOError, if an I/O error occurs during file sharing.

    • with error type AbortError, if any other error occurs.

Code example:

var port = proxy.getPort(tizen.rpcport.PortType.MAIN);
var path = tizen.application.getAppSharedPath() + "data.txt";
port.shareFile(path);
shareFiles
Shares multiple private files through the port. 
void shareFiles(DOMString[] paths);

Since: 10.1

The file paths must be under the caller application's data path. The target application will be granted temporary permission to access the files.

Parameters:

  • paths: The array of file paths to share.

Exceptions:

  • WebAPIException

    • with error type TypeMismatchError, if paths is not an array of strings.

    • with error type InvalidValuesError, if the port handle is invalid or paths are invalid.

    • with error type IOError, if an I/O error occurs during file sharing.

    • with error type AbortError, if any other error occurs.

Code example:

var port = proxy.getPort(tizen.rpcport.PortType.MAIN);
var paths = [
  tizen.application.getAppSharedPath() + "data1.txt",
  tizen.application.getAppSharedPath() + "data2.txt"
];
port.shareFiles(paths);

2.6. ProxyBase

The ProxyBase interface provides client-side proxy functionality. 
  [Constructor(DOMString appid, DOMString portName)]
  interface ProxyBase {
    [TreatNonCallableAsNull] attribute Function? onConnected;
    [TreatNonCallableAsNull] attribute Function? onDisconnected;
    [TreatNonCallableAsNull] attribute Function? onRejected;
    void connect() raises(WebAPIException);
    void connectAsync(SuccessCallback successCallback, optional ErrorCallback? errorCallback) raises(WebAPIException);
    Port getPort(PortType portType) raises(WebAPIException);
    void onReceived(Parcel parcel);
  };

Since: 10.1

ProxyBase is used to connect to a remote stub and communicate with it. It manages the connection lifecycle and message reception.

Constructors

Constructor (DOMString, DOMString) 
ProxyBase(DOMString appid, DOMString portName);

Attributes

  • Function onConnected [nullable]
    Called when the proxy connects to a stub.

    This is an empty placeholder method that should be overridden by derived classes or application.

    Since: 10.1

    Code example:

    var proxy = new tizen.rpcport.ProxyBase("com.example.targetapp", "myport");
proxy.onConnected = function(receiver)
{
  console.log("Connected to: " + receiver);
};
  • Function onDisconnected [nullable]
    Called when the proxy disconnects from a stub.

    This is an empty placeholder method that should be overridden by derived classes or application.

    Since: 10.1

    Code example:

    var proxy = new tizen.rpcport.ProxyBase("com.example.targetapp", "myport");
proxy.onDisconnected = function(receiver)
{
  console.log("Disconnected from: " + receiver);
};
  • Function onRejected [nullable]
    Called when the proxy connection is rejected by the stub.

    This is an empty placeholder method that should be overridden by derived classes or application.

    Since: 10.1

    Code example:

    var proxy = new tizen.rpcport.ProxyBase("com.example.targetapp", "myport");
proxy.onRejected = function(receiver)
{
  console.log("Rejected by: " + receiver);
};

Methods

connect
Connects to the remote stub synchronously. 
void connect();

Since: 10.1

Privilege level: public

Privilege level: public

Privilege: http://tizen.org/privilege/appmanager.launch

Privilege: http://tizen.org/privilege/datasharing

Parameters:

  • successCallback: The method to invoke on successful connection.
  • errorCallback [optional] [nullable]: The method to invoke on error.

Exceptions:

  • WebAPIException

    • with error type SecurityError, if the required privileges are not granted.

    • with error type TypeMismatchError, if any input parameter is not compatible with the expected type.

Code example:

var proxy = new tizen.rpcport.ProxyBase("com.example.targetapp", "myport");
proxy.connectAsync(
    function()
    {
      console.log("Connected successfully");
    },
    function(err)
    {
      console.log("Error: " + err.message);
    });

Since: 10.1

2.7. StubBase

The StubBase interface provides server-side stub functionality. 
  [Constructor(DOMString portName)]
  interface StubBase {
    void listen() raises(WebAPIException);
    void addPrivilege(DOMString privilege) raises(WebAPIException);
    void setTrusted(boolean trusted) raises(WebAPIException);
    Port getPort(DOMString instance, PortType portType) raises(WebAPIException);
    void onConnected(DOMString sender, DOMString instance);
    void onDisconnected(DOMString sender, DOMString instance);
    void onReceived(DOMString sender, DOMString instance, Parcel parcel);
  };

Since: 10.1

StubBase listens for incoming proxy connections and handles communication. It can require privileges and certificates for connection authorization.

Constructors

Constructor (DOMString) 
StubBase(DOMString portName);

Methods

listen
Starts listening for incoming proxy connections. 
void listen();

Since: 10.1

Exceptions:

  • WebAPIException

    • with error type InvalidValuesError, if the stub handle is invalid.

    • with error type IOError, if an I/O error occurs during listening.

    • with error type AbortError, if any other error occurs.

Code example:

var stub = new tizen.rpcport.StubBase("myport");
stub.listen();
addPrivilege
Adds a required privilege for proxy connections. 
void addPrivilege(DOMString privilege);

Since: 10.1

Proxies must have the specified privilege to connect to this stub.

Parameters:

  • privilege: The privilege URI.

Exceptions:

  • WebAPIException

    • with error type TypeMismatchError, if privilege is not a string.

    • with error type AbortError, if any other error occurs.

getPort
Gets a port for the specified instance and type.

Since: 10.1

The instance identifier is provided by the platform and should be obtained from the onConnected callback parameter.

Parameters:

  • portType: The type of port to get.

    Port: The Port instance.

    • with error type TypeMismatchError, if any parameter is not of the expected type.

    • with error type AbortError, if any other error occurs.

module RPCPort {
  enum PortType { "MAIN", "CALLBACK" };
  Tizen implements RPCPortObject;
  [NoInterfaceObject] interface RPCPortObject {
    readonly attribute RPCPortManager rpcport;
  };
  [Callback=FunctionOnly, NoInterfaceObject] interface RPCPortEventCallback {
    void onreceived(octet[] data);
  };
  [NoInterfaceObject] interface RPCPortManager {
    Parcel createEmptyParcel() raises(WebAPIException);
    Parcel createParcelFromPort(Port port) raises(WebAPIException);
    Parcel createParcelFromBytes(octet[] bytes) raises(WebAPIException);
    void publishEvent(DOMString eventName, octet[] bytes) raises(WebAPIException);
    long addEventReceiver(DOMString eventName, RPCPortEventCallback listener) raises(WebAPIException);
    void removeEventReceiver(long watchId) raises(WebAPIException);
  };
  interface Parcel {
    octet[] toBytes();
    void send(Port port) raises(WebAPIException);
    void setTagEx(octet major, octet minor, octet patch, octet proto, octet flags) raises(WebAPIException);
    long getSeqNum() raises(WebAPIException);
    void dispose() raises(WebAPIException);
    void writeByte(byte value) raises(WebAPIException);
    void writeInt16(short value) raises(WebAPIException);
    void writeInt32(long value) raises(WebAPIException);
    void writeInt64(long long value) raises(WebAPIException);
    void writeDouble(double value) raises(WebAPIException);
    void writeBool(boolean value) raises(WebAPIException);
    void writeString(DOMString value) raises(WebAPIException);
    void writeArrayCount(unsigned long count) raises(WebAPIException);

    byte readByte() raises(WebAPIException);
    short readInt16() raises(WebAPIException);
    long readInt32() raises(WebAPIException);
    long long readInt64() raises(WebAPIException);
