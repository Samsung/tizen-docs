
# Event Handling


The Tizen platform supports handling events from media input devices.

<a name="media"></a>
## Media Key Events


Tizen supports handling **Media** key events, such as play, stop, and
pause events, from media devices (such as Bluetooth remote controller
and earjack).

To handle the **Media** key events, use the Media key API ([API reference](../../api/common/latest/group__CAPI__SYSTEM__MEDIA__KEY__MODULE.html)).
